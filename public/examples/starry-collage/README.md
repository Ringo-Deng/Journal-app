# 拾光拼贴示例

经用户要求，从本机手帐对应页面提取装饰与排布，用于安装包内置示例。保留原始素材像素、位置、大小、旋转及图层顺序；没有从截图重新绘制。

包含星空底纸、横线纸、两条胶带、硫酸纸、星空纸角、数字邮票和 September 装饰贴纸。已移除照片、正文、日记记录、原本子与页面标识、素材库内部标识以及编辑历史。数字与月份是原装饰图案的一部分。

第二跨页为绿色拼贴：保留两侧底纸、心形撕纸、星星与小花衬纸、图钉、蝴蝶结、胶带、水滴、烟花、夹子、星星及日期装饰，共 17 个元素；移除四张照片及全部正文。`green-` 素材直接取自用户指定的本地原页，按原始坐标、尺寸、旋转与图层顺序排列。

这些素材来自用户本地素材库；本文件不将其标记为公版或另行授予第三方许可。

`book.json` 只描述这一示例本。桌面首次启动且不存在 journal.json 或 journal.previous.json 时，由 `local/example-notebook.mjs` 安装；保存过的空笔记库也不会再次添加。图片按内容摘要复制到用户 uploads，沿用现有编辑、保存、导出与备份链路。用户原本子不变。
