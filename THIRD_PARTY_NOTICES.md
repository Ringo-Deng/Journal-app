Source: https://github.com/MengTo/threeui/blob/main/public/landing-pages/meng-to-sketchbook.html

It uses the existing book geometry, input state and locally generated sample artwork. The original CSS renderer and artwork are not bundled. Main appreciation mode keeps its original profile.
