# Windows 桌面测试版

面向 Windows 10/11 x64，内置运行环境，无需安装 Node.js 或 Git。尚未完成普通 Windows 电脑上的人工全功能验收；ARM 和 32 位系统不在首版验收范围。

## 打开和更新

1. 将下载的 ZIP 完整解压到一个普通文件夹（不要在压缩包内直接运行）。
2. 双击文件夹里的「拾光手帐.exe」。保留同目录的 resources、DLL 等文件，不能只复制 exe。
3. ZIP 便携版仍需手动更新；推荐改用下文的安装版，首次安装后支持自动更新。

本测试包没有 Windows 代码签名，可能出现发布者未知或 SmartScreen 提示。请核对下载来源；不要关闭系统安全防护。正式发行仍需签名及另一台 Windows 电脑验收。

## 资料与迁移

手帐保存在 `%APPDATA%\ShiguangJournalDesktop\data`，AI 配置在同级 `config`。应用菜单的「打开资料文件夹」可定位。替换程序不会替换这个目录；删除程序文件夹也不会清除资料。

首次打开不会自动搬动源码版或 Mac 版资料。请在旧版导出「完整资料备份」，在新版中追加恢复；保留原始资料和备份，确认图片、手帐均可读取后再使用。AI 密钥需单独设置，分享包不带密钥。Mac 与 Windows 不会自动同步。

退出前会等待保存；保存冲突、失败或图片处理未完成时会阻止退出。不要用任务管理器结束应用作为正常退出方法。

## 功能范围

共用现有编辑、阅读、备份及 AI 界面。Windows 图片兼容引擎可处理透明图、白底和单色背景；复杂照片的自动识别效果不等同于 Mac Vision，可使用原图裁切。语音输入未作为桌面支持能力。

## 翻页音效检查

如果编辑或 3D 阅读没有声音，打开应用顶部「拾光手帐」菜单，选择「检查翻页音效」。程序会依次播放编辑、阅读两段音效，并显示播放结果；检查失败时保留具体错误。检查完成仍听不到声音时，核对系统音量混合器中本应用选用的输出设备，而不只是总音量。

## 开发与验证

在 Windows x64、Node.js 22.21.0 或更新环境执行 `npm ci`，再执行 `npm run desktop:windows`。应用目录生成在 `build/desktop/拾光手帐-win32-x64/`。

GitHub Actions 的「Windows desktop」任务在 Windows runner 上构建，执行相关回归，并对解压后的应用副本做隔离启动、页面加载、三段音效解码与播放完成、保存回读、重新启动与正常退出检查。通过后上传带版本号的 ZIP；在该任务页面的 Artifacts 下载。自动检查不能证明实体扬声器发声，也不能替代拖拽、3D 翻页、完整备份迁移、付费 AI 及 SmartScreen 的人工验收。

## 安装版自动更新（v0.1.277 起）

首次请下载 `shiguang-journal-v<版本>-windows-x64-setup.exe` 并运行。此前使用 ZIP 便携版的用户也需要手动安装这一次；安装版沿用 `%APPDATA%/ShiguangJournalDesktop` 中的手帐及配置，不搬移、不清空旧数据。之后从新安装的快捷方式启动，避免继续打开旧 ZIP 中的程序。

安装版启动约 10 秒后自动检查正式发布版本并在后台下载；菜单「拾光手帐 → 检查更新」可手动重试，并显示下载进度。下载完成可选择「重启更新」或「稍后」。正常退出时也会安装已下载的更新。任何安装操作必须先通过页面保存和后台任务结束检查；保存冲突或仍有任务时留在当前应用。断网、下载失败、校验失败不会安装，当前版本可继续使用。应用仍未签名，系统可能显示发布者提示；Mac 暂不接入自动更新。

发布流程：Windows 工作流生成 NSIS 安装包、`.blockmap` 与 `latest.yml`，通过安装、音效、保存及重启测试后作为工作流产物提供，CI 维持仓库只读权限。发布者将验证后的三个文件上传到同版本 GitHub Release 草稿，核对版本、测试与发布内容后发布为正式 Release（非 prerelease），更新器才会发现它。不要先发布清单再上传安装包，不覆盖已公开版本；修复应升新版本。ZIP 产物保留作兼容测试，不作为自动更新安装入口。
