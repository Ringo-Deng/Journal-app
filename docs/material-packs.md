# 分享处理好的素材

从 v0.1.264 开始，网页与 Mac 桌面版共用素材包功能。双方都需要支持此功能的版本。

## 导出

1. 将素材工作台里需要分享的处理结果先入库。
2. 打开素材库，按分类、标签或名称筛选，勾选要分享的素材；也可以「全选当前结果」。
3. 点击「导出所选素材包」，保存 `.shiguang-materials` 文件。

每包最多 200 件、256 MB；单张图片最多 16 MB，支持 PNG、JPG、WebP 静态图片。只包含选中的当前成品图片、名称、分类、标签、作者和许可文字；不打包原始整图、照片库、手帐、AI 配置或素材处理历史。图片文件保持原样，透明度不变。

## 导入

在素材库点击「导入素材包」选择该文件。完成校验后追加入库，名称、分类和标签可直接使用。相同图片文件按 SHA-256 跳过，即使来自不同素材包也不重复添加；已有素材的名称与标签不被替换。不同编码或压缩结果视为不同图片。

素材包是拾光专用格式，不是 ZIP，也不是完整资料备份，请使用对应入口。损坏、截断、超限、含异常路径或未声明文件的包会在入库前拒绝。文件先写入，再原子更新素材索引；索引写入失败会移除本次新文件，已有资料保持不变。导入失败可能留下已新增的空分类/标签词条，不会修改已有素材或手帐。

导出不自动选择你的私人素材；需由你确认勾选范围后生成。内置与自有素材均可勾选，但原始整图不会随成品自动附带。
