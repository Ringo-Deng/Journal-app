# AI 手帐排版参考规则

根据用户提供的两张手工手帐拼贴图，提炼可复用的排版关系，供 AI 创作使用。

- **配色有主次**：每页以少数协调主色为基础，用一点撞色点亮；柔和与鲜明配色均可，纯色纸衬托图案纸。
- **纸片形成层次**：大小不同的底纸错位叠贴，露出边缘，辅以撕边或胶带。通常以两三层为起点，按文字和照片空间调整。
- **每页突出一个主视觉**：正文、照片或主贴纸形成重心，小标签等靠纸边和转角集中点缀。
- **保留连续留白**：先放下全文与照片，再安排装饰；允许文字主导一页，避免把空位都填上贴纸。
- **构图有变化**：参考上下呼应、斜对角重心和中央框景。每页独立成形，跨页用配色或材质呼应。

共享规则位于 [`local/reference-layout-guide.mjs`](../local/reference-layout-guide.mjs)，由短文选材 [`local/paper-group.mjs`](../local/paper-group.mjs)、视觉方案提示 [`local/art-direction.mjs`](../local/art-direction.mjs) 和完整排版提示 [`local/layout-prompt.mjs`](../local/layout-prompt.mjs) 复用。默认采用适中疏密 `balanced`；用户明确要求密集或极简时，仍可使用 `rich` 或 `sparse`。现有照片构图、长文构图及内容保留规则继续适用。

短文由 AI 选择零至两张衬纸，加一张按全文尺寸生成的书写纸，总共一至三层。真实底纸在候选中标记为纸张，保留原始图片、透明轮廓和比例，可以上下、左右露边或斜向叠接；也可以选生成衬纸。书写纸支持直边、撕边、票券和椭圆，花纹可选素色、格纹、圆点或横线，宽度与对齐由 AI 决定，高度按全文计算。胶带不再自动补两段。

真实纸张可能自带字迹或透明区域，因此作为纹理衬纸；正文仍由不透明、对比足够的书写纸承载。文字不会因纸张过小而缩小字号；组合超出纸面或挡住已有内容时，要求 AI 重选或明确失败。缺少新的书写纸与衬纸字段时会重试，不再静默回退到旧双矩形模板。已保存的页面无需迁移，已有组合继续受保护；新规则用于新生成或未编组文字的重设计，不会自动替换旧组合。

长文与照片仍通过原有路径选择布局，斜向照片需要自由构图；疏密参数用于指导模型，不是硬性的素材数量限制。

此次“学习”是将观察到的设计原则写入应用的提示与构图规则，没有微调模型，也没有把参考图片上传到外部模型或加入素材库。图中的文字、装订孔、拍摄背景、水印和具体角色不作为生成内容。效果仍取决于当前可用素材和模型输出，不保证复刻参考图中的造型；用户的具体要求优先，既有文字、照片和锁定组合应完整保留。
