## 交付范围与限制

- 安装包为 ZIP 内的 `.app`，首版不制作 DMG 或自动更新器。
- 仅支持 Apple 芯片与 macOS 26+：四个现有原生程序的 Mach-O 最低系统版本都是 26.0。本轮没有修改或重新编译这些程序。
- 仅 ad-hoc 签名；没有 Developer ID 签名、公证，也未在第二台 Mac 的隔离下载环境中验证 Gatekeeper。不能作为已完成正式发行验收的版本。
- 未实际调用付费 AI、验证语音输入或在桌面包中逐项重测全部编辑操作；不能宣称功能全量验收通过。首版桌面权限默认拒绝，语音输入不作为已支持能力。
- 完整备份仍复用原有入口与保存链路，本轮没有用真实旧手帐执行导入迁移，也未验证跨版本升级，仅验证本版本重新打包替换后数据保留。
- 数据默认独立存放在 `~/Library/Application Support/ShiguangJournalDesktop/`。不自动读取、搬动或覆盖源码版资料。用户迁移应通过完整备份追加恢复，保留原始资料与备份后回读核验。
- 打包只读取受控运行时和公共资源、构建页面及 sharp 的依赖闭包；不包含个人数据、AI 密钥、Git 历史或开发依赖。
